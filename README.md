# Chitai Gorod Book Finder — «Что почитать»

Учебный веб-прототип подбора книг по настроению, времени и читательскому опыту для «Читай-города». Имя проекта и репозитория: `chitai-gorod-book-finder`.

Приложение на React, TypeScript и Vite. Оно следует экспортированным CJM и схеме экранов, сохраняя веб-формат: опрос, рекомендации, чтение, получение книги и обратная связь после покупки.

Подробная сверка этапов и ограничений: [docs/CJM.md](docs/CJM.md). Исходные PDF лежат в `docs/references/`.

## Запуск

Нужен Node.js 22.12+ и npm.

```sh
npm ci
npm run dev
```

Открыть адрес из терминала, обычно http://localhost:5173.

```sh
npm run build
npm run preview
```

Сборка находится в `dist/` и подходит для статического хостинга, в том числе в подпапке. Маршруты с `#` не требуют серверных перенаправлений. Открывать сборку следует через HTTP-сервер.

Книги, обложки и шрифты хранятся локально. Длинные отрывки загружаются отдельным модулем при открытии читалки. Внешние запросы из пользовательского сценария нужны только при переходе по ссылке на источник текста.

## GitHub Pages

Сайт: [1ef7yy.github.io/chitai-gorod-book-finder](https://1ef7yy.github.io/chitai-gorod-book-finder/).

Публикация настроена через [GitHub Actions](.github/workflows/deploy-pages.yml). После каждого push в `main` workflow устанавливает зависимости, запускает тесты, собирает приложение и публикует `dist/` в GitHub Pages. Его также можно запустить вручную: `Actions → Deploy to GitHub Pages → Run workflow`.

В `Settings → Pages → Build and deployment → Source` должен быть выбран `GitHub Actions`. Текущие `base: './'` и `HashRouter` позволяют разместить сборку в подпапке репозитория. Прямая ссылка на читалку: [Белые ночи](https://1ef7yy.github.io/chitai-gorod-book-finder/#/read/white-nights).

## Сценарий показа на защите

1. На главной нажать «Подобрать книгу». Выбрать «Вечер», затем «Отвлечься» и «Вдохновиться». Можно отметить до двух настроений или выбрать «Удиви меня».
2. Выбрать понравившиеся книги либо пропустить последний вопрос. Поиск понимает, например, опечатку `достоевскии`.
3. После загрузки в течение 2,5 секунды появятся три рекомендации. Сравнить объяснения, время на всю книгу и цены.
4. Проверить «Другие варианты» и «Не то настроение». Второе действие позволяет поменять настроение, сохранив время и любимые книги, без повторного прохождения всей анкеты.
5. Нажать «Читать отрывок»: доступны 3–4 экранные страницы начала произведения, настройка шрифта и тёмная тема. Перейти на следующую страницу и обновить вкладку: закладка и настройки сохранятся.
6. Из читалки нажать «Взять в магазине», выбрать самовывоз, район у метро и магазин, затем забронировать. Подтверждение показывает адрес, время выдачи и срок демоброни.
7. Нажать «Посмотреть вопрос» в блоке про 5–7 дней. Это демонстрация будущего этапа, ждать не требуется. Пройти один из ответов: «Читаю, нравится», «Не начал(а)» или «Не моё».
8. При положительном или отрицательном ответе открыть новую подборку. При ответе «Не начал(а)» показать одно напоминание и вернуться к закладке. Кнопка «Не спрашивать о чтении» отключает вопросы в этой вкладке.

Для проверки альтернативной ветки открыть `/#/pickup/white-nights`: в двух магазинах нет книги. Можно запросить демоуведомление, найти другой магазин или купить электронную версию. Покупка также поддерживает бумажную книгу с демонстрационной доставкой.

Все оплаты, брони, сообщения и сроки демонстрационные. Никакие реальные заказы или уведомления не создаются, данные карты не запрашиваются. Для доставки можно оставить вымышленный адрес из примера. Электронный демозаказ выдаёт ссылку на отрывок; полный текст можно открыть на Викитеке.

## Подбор и сохранение

Каталог содержит 24 настоящие книги. Ситуация чтения задаёт группу объёма: для дороги короткие произведения, для вечера повести, для выходных и отпуска более длинные книги. Отдельная метка показывает примерное время на книгу целиком.

Алгоритм сначала учитывает число совпавших настроений, затем общие жанры с любимыми книгами и отзывы из предыдущих демопокупок. «Удиви меня» снимает фильтр настроения. Если точных совпадений мало, карточки честно называют остальные книги альтернативами нужного объёма.

Любимые, купленные и уже оценённые книги не предлагаются снова. Отрицательная оценка снижает приоритет общих тем. При перегенерации используются книги вне текущей тройки; когда альтернатив мало, повторы допустимы. Если своего объёма не хватает для нужного настроения, алгоритм предлагает более короткие книги и отмечает это в объяснении. Длиннее выбранного объёма книги не предлагаются. При исчерпании всех подходящих книг выдача может содержать меньше трёх, и интерфейс предлагает изменить время.

Ответы, выдача, формат, магазин, закладки, настройки чтения и оценки сохраняются в `sessionStorage`, ключ `chitai-selection-v2`. «Подобрать ещё книгу» очищает анкету, сохраняя историю и обратную связь. После закрытия вкладки браузер может удалить состояние. При недоступном хранилище сценарий работает в памяти. Старая версия данных `v1` не переносится: смысл вопроса о времени изменился.

Локальные события для воронки CJM записываются под ключом `chitai-events-v1`. Они не отправляются на сервер. Перечень событий и ограничения метрик описаны в `docs/CJM.md`.

## Материалы и ограничения

Каталог и теги находятся в `src/data.ts`, алгоритм в `src/recommend.ts`. Аннотации написаны для прототипа. Длинные отрывки в `src/reader-excerpts.json` взяты из русскоязычных произведений в общественном достоянии, со ссылкой на источник каждого текста. Разбивка на экранные страницы условная и не соответствует печатному изданию. После изменения отрывков обновить небольшую таблицу количества страниц:

```sh
node scripts/update-reader-meta.mjs
```

Обложки в `public/covers/` являются оригинальными векторными макетами серии «Истории вне времени», а не изображениями конкретных изданий. Пересоздать их можно командой `python scripts/make-covers.py`. Noto Sans хранится локально с лицензией OFL в `public/fonts/OFL.txt`; иконки из Lucide.

Цены, страницы, длительность чтения, наличие, доставка, время выдачи и срок брони являются демоданными. Карта схематическая, геолокация не запрашивается. Можно выбрать деморайон у метро в Москве; магазин у выбранного метро показывается первым, расстояния и реальные маршруты не рассчитываются.

## Проверка

```sh
npm test
npm run build
```

В среде разработки проходят 141 тест Vitest и проверка TypeScript. Они включают все одиночные и парные сочетания настроений, ранжирование с обратной связью, опечатки в поиске, сохранность текстов при разбиении на страницы и 17 сценариев с отрисовкой React в jsdom: чтение, три способа получения, отсутствие книги, смена района, отмена подбора, обратная связь, одно напоминание, отказ от вопросов и восстановление состояния.

Подготовлены четыре браузерных сценария на ширинах 360, 390 и 1440 px, всего 12 проверок:

```sh
npx playwright install chromium
npm run test:e2e
```

Для системного Chromium:

```sh
CHROMIUM_PATH=/usr/bin/chromium npm run test:e2e
```

Браузерный набор проверен на обнаружение тестов, но не выполнен: в текущей среде запуск браузера и локального сервера заблокирован. Внешний браузерный инструмент также не запускается из-за отсутствующего Google Chrome. jsdom проверяет поведение, но не внешний вид и размеры элементов; перед защитой нужен просмотр в обычном браузере.
