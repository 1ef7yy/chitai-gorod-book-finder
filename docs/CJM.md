# Соответствие CJM веб-прототипу

Источники: [CJM](references/CJM.pdf) и [схема экранов](references/screens.pdf), экспортированные из Miro 2 ноября 2026 года. По решению пользователя приложение остаётся веб-страницей с существующим оформлением.

| Этап схемы | Веб-реализация |
| --- | --- |
| 1. Пост в Telegram | Его роль выполняет главная страница с обложками, обещанием трёх рекомендаций и кнопкой подбора. Параметр `utm_source` можно передать в адресе сайта. Настоящий пост не публикуется. |
| 2. Стартовый экран | Главная объясняет три вопроса и возможность прочитать отрывок; регистрация не нужна. |
| 3. Время | `/quiz/time`: дорога на 15–20 минут, вечер, выходные, отпуск. Подсказки по объёму, прогресс 1 из 3. |
| 4. Настроение | `/quiz/mood`: отвлечься, посмеяться, поплакать, подумать, пощекотать нервы, вдохновиться. Одно-два настроения или «Удиви меня». |
| 5. Читательский опыт | `/quiz/books`: поиск с исправлением опечаток, популярные обложки, до трёх книг, необязательный шаг. |
| 6. Три варианта | `/results`: обложка, автор, название, длительность всей книги, причина, бумажная цена, чтение, покупка, магазин. |
| 7. Отрывок | `/read/:id`: начало произведения на 3–4 экранных страницах, размер шрифта, тёмная тема, закладка, закреплённые цена и действия покупки. Возврат сохраняет подборку. |
| 8. Способ получения | `/receive/:id`: электронная книга, бумажная с доставкой, самовывоз. |
| 9. Оформление | `/checkout/:id` или `/pickup/:id`: демооплата либо карта и наличие. Выбор метро задаёт деморайон, магазин у выбранного метро показывается первым. |
| 10. Подтверждение | `/done`: книга, формат, сумма; для брони адрес, время выдачи и срок; для электронной книги ссылка на чтение. Вместо сообщения в боте используется страница подтверждения. |
| 11. Вопрос через 5–7 дней | `/follow-up/:id`: «Читаю, нравится», «Не начал(а)», «Не моё», отключение вопросов. Переход «Посмотреть вопрос» демонстрирует будущий этап сразу. |
| 12. Следующая подборка | Повторный подбор учитывает оценку. Понравившаяся книга добавляет вес общим темам, отрицательная снижает их приоритет. Купленные и оценённые книги исключаются. |

## Дополнительные ветки

- «Другие варианты» заменяет тройку, если есть альтернативы. «Не то настроение» ведёт сразу ко второму вопросу; время и любимые книги сохраняются, повторно проходить анкету не требуется.
- Если оба магазина без наличия, нельзя создать бронь. Доступны электронная версия, другой магазин и отметка «Сообщить, когда появится». В демо для «Белых ночей» показана именно эта ситуация.
- «Не начал(а)» сохраняет возможность вернуться к закладке. Одно демонапоминание показывается по кнопке, без повторов. «Не спрашивать о чтении» отключает следующие вопросы в этой вкладке.
- Исчерпание локального каталога не возвращает бесконечно на загрузку. Приложение показывает оставшиеся книги или предлагает изменить время.

## Что означает время

Вопрос относится к ситуации чтения, а не к обещанию закончить любую книгу за 20 минут. Для дороги предлагаются короткие произведения, которые можно читать частями. В карточке отдельно указан приблизительный срок на книгу целиком.

Четыре ситуации соответствуют четырём предпочтительным группам объёма. При недостатке совпадений по настроению допустима более короткая книга: для выходных может подойти и повесть. Более длинные книги не предлагаются. Короткая альтернатива отмечается в объяснении. Приблизительные часы используются для группировки; это редакционные демоданные, а не измерение скорости конкретного читателя.

## Что имитируется

Все действия происходят внутри сайта. Бот, авторизация, настоящая оплата, доставка, уведомления и магазинные остатки не подключены. Город и районы демонстрационные; реальная геолокация не запрашивается. Электронный демозаказ открывает отрывок, а полный текст доступен на Викитеке. Разбивка отрывка на экраны не повторяет печатное издание.

Отрывки сохраняются локально, каждый со ссылкой на источник. Для «Гранатового браслета» взяты начало первой и второй главы, поскольку первая глава короткая; для сборника Гоголя используется начало «Ночи перед Рождеством».

## Метрики

В `sessionStorage`, ключ `chitai-events-v1`, записываются локальные события:

| Событие | Что можно проверить |
| --- | --- |
| `page_view`, `selection_started` | Входы в веб-сценарий и переход к подбору, включая метку источника |
| `quiz_step` | Прохождение вопросов, выбранные ситуации и настроения, заполнение или пропуск опыта |
| `results_ready`, `regenerate`, `change_mood` | Получение и изменение рекомендаций |
| `excerpt_opened`, `excerpt_page`, `excerpt_completed` | Открытие, страницы и достижение конца отрывка |
| `purchase_intent`, `format_selected`, `order_confirmed` | Выбор способа получения и завершение демозаказа |
| `alternative_store`, `stock_alert` | Действия при отсутствии книги в магазине |
| `reading_feedback`, `reading_reminder`, `followup_opt_out`, `next_recommendations` | Ответ после покупки, одно напоминание, отказ от вопросов и повторный подбор |

Достижение конца отрывка определяется его появлением в поле зрения или явным подтверждением читателя; это не доказательство внимательного прочтения. Показы Telegram-поста, фактические оплаты и выкупленные брони потребуют настоящих интеграций. Демо не доказывает рост продаж или дочитываний.
